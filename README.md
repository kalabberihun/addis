# Addis Song Manager

A full‑stack MERN application for managing songs. It provides a RESTful API (Express + TypeScript + MongoDB) and a modern React frontend (Vite + TypeScript, Redux Toolkit, Redux‑Saga, Emotion).

## Project Structure
```
addis-song-manager/
├─ backend/      # Express API
├─ frontend/     # React UI
├─ docker-compose.yml
├─ README.md
└─ .gitignore
```
